# Screenshots

This directory is reserved for lightweight screenshots used in the README, GitHub repository page, and release notes.

Current screenshots:

- `results-overview.png`: Results tab with graph controls, summary table, and volume-time plot.

Suggested captures:

- input source selection for local and SSH/SFTP workflows;
- result table after analyzing a small synthetic or publishable case;
- volume, equivalent radius, contact angle, and contact radius plots;
- visualization diagnostics showing contact-fit points and geometry.

Guidelines:

- Do not include private hostnames, usernames, SSH paths, passwords, keys, or unpublished research data.
- Prefer synthetic data, public sample data, or a cropped view that does not reveal sensitive information.
- Keep image files reasonably small for the repository.
- Use descriptive filenames such as `results-table.png` or `contact-fit-diagnostics.png`.
