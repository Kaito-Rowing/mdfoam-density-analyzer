# Support

## Questions and Usage Help

For general usage questions, open a GitHub Discussion if Discussions are enabled. If Discussions are not available, open a GitHub Issue and choose the most appropriate template.

Useful information to include:

- operating system;
- Python version;
- how you installed dependencies;
- whether the case is local or accessed through SSH/SFTP;
- density field name;
- a minimal directory structure or small text fragment that reproduces the issue.

## Bug Reports

Use the bug report template when the application crashes, produces unexpected output, cannot parse an OpenFOAM ASCII file, or behaves unexpectedly in the GUI.

Please do not attach large mdFOAM/OpenFOAM case directories. Use synthetic data or small text snippets whenever possible.

## Feature Requests

Use the feature request template for workflow improvements, additional export formats, supported field variants, visualization improvements, or analysis options.

Because this project is intentionally focused on direct Python processing, requests that require ParaView or pvpython as runtime dependencies are unlikely to be accepted.

## Security

For sensitive SSH/SFTP, credential storage, private key, password, or remote file access concerns, follow `SECURITY.md` instead of opening a public Issue.
